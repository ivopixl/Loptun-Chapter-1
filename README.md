# Loptun: La légende de Kane — HTML5 (v0.4)

Conversión y remasterización experimental del juego original QuickBASIC de **IVOSOFT**.

## Jugar

- **Remastered:** abre [index.html](index.html) (edición predeterminada).
- **Clásico:** abre [clasico.html](clasico.html).
- Ambos HTML funcionan de forma autónoma en navegadores modernos.
- Incluyen teclado, mando/joystick (Gamepad API), sonido Web Audio y guardado local.

## Contenido

| Ruta | Contenido |
| --- | --- |
| `index.html` | Loptun Remastered v0.4 |
| `clasico.html` | Loptun Clásico v0.4 |
| `original/` | Fuentes QuickBASIC y recursos originales proporcionados por el autor |

## Controles

Usa las flechas para desplazarte, `Espacio` para actuar y `5` para cambiar la actitud.
`Esc` o `F10` pausa el juego. El código `1234` activa el acceso administrador a los capítulos.
La versión Remastered permite consultar la referencia VGA original con `F6`.

## Publicar en GitHub Pages

En **Settings → Pages**, elige `Deploy from a branch`, rama `main` y carpeta `/(root)`.
Al activarlo, el juego estará disponible en `https://ivopixl.github.io/Loptun-Chapter-1/`.

## Estado de desarrollo

**Beta v0.4:** se ha comprobado el arranque de los cuatro actos y parte de las animaciones, pero no todos los acertijos y recorridos completos. El Remastered renueva la presentación 2.5D manteniendo la base de aventura original.
